## Playwright — known stale baseline, not a v0.2 regression

Tagged `v0.1.40` Playwright specs still expect **CLIProxyAPI sidecar** chrome (`mock sidecar reply`, `CLIProxyAPI sidecar`) after the product removed the EasyCLI sidecar runtime.

That mismatch is a **pre-existing 0.1.40 test-contract gap**. v0.2 must not import the parked OAuth/proxy WIP solely to make those specs green. Playwright is a separate platform-smoke surface, not part of the A0–A2 freeze gate.

## Known concurrency test concern — `context_pack_boundary`

**Not an A9 blocker.** Recorded so later hits are not silently normalized.

At A8 freeze, one `cargo test --workspace --no-fail-fast` run failed inside `context_pack_boundary`:

- `can_suggest_does_not_generate_suggestion` — `WorkspaceMismatch`
- `cannot_answer_authority_remains_declarative_metadata` — `AtomicReplaceFailed` (`ENOENT`)

Isolation:

- `cargo test -p openmesh-core --test context_pack_boundary -- --test-threads=1` → 14 passed
- Immediate full workspace rerun → 2146 passed, 0 failed, 1 ignored

Treat future occurrences as a **parallel-load storage/concurrency test concern**. Re-isolate with `--test-threads=1`, record the hit, and do not weaken assertions or skip the test to keep a freeze green.
