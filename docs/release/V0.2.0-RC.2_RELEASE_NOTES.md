# OpenMesh v0.2.0-rc.2 Release Notes

- **Release Candidate:** `2`
- **Tag / Baseline:** `v0.2.0-rc.2`
- **Date:** 2026-09-10

OpenMesh `v0.2.0-rc.2` is a targeted packaging release candidate that resolves Windows prerelease installer generation. No Agent Workbench runtime behavior or product code has changed.

---

## Changes in RC.2

### Packaging & Release Automation
- **Windows NSIS Prerelease Target:** Fixed Windows release packaging by configuring the release matrix to build NSIS bundles (`--bundles nsis`). WiX MSI installer bundling fails on alphanumeric prerelease versions (such as `0.2.0-rc.1` / `0.2.0-rc.2`) due to Windows Installer's strict numeric ProductVersion constraints (`optional pre-release identifier in app version must be numeric-only and cannot be greater than 65535 for msi target`).
- **Release Regression Guard:** Enhanced `scripts/check-release-workflow.mjs` with an automated regression check ensuring that whenever the project version contains a prerelease identifier, the Windows release workflow matrix strictly targets NSIS, preventing recurrence in future prerelease builds.
- **Manifest Synchronization:** Synchronized version declarations to `0.2.0-rc.2` across `package.json`, `package-lock.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, `crates/openmesh-core/Cargo.toml`, `crates/openmesh-cli/Cargo.toml`, and `Cargo.lock`.
