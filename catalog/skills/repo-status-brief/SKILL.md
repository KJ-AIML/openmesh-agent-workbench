# Repo Status Brief

If the user asks for status, health, or "where are we":
1. Use available tools (`git_status`, Continuity summaries) before answering.
2. Lead with a 2–4 line brief: branch/dirty state, top Continuity signal, one next step.
3. Do not invent commits, PRs, or mesh peers.
