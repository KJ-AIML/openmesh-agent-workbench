# Continuity Brief

When summarizing project status for OpenMesh:
1. Prefer Continuity Current State / pending attention tools when available.
2. Format: **Now** (one line) → **Pending** (bullets) → **Suggested next** (one action).
3. Never invent mesh, team, or trust facts.
